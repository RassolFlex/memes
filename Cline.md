# Cline — инструкция для меня самого

## Проект
**YouTube-шаблоны / мемы для монтажа** — локальная библиотека видеомемов для быстрого поиска и использования при монтаже YouTube-видео.

## Что важно помнить
- **Код пишется на Python** (backend) и HTML/JS/CSS (фронтенд)
- **Структура папок жёстко иерархична** — не менять без крайней необходимости
- **Имена файлов** — читаемые, в кириллице, без спецсимволов
- **Никакого "мусора"** — не оставлять закомментированный код, temp-файлы, пустые папки
- **Не использовать** git blame/history — это не для этого

## Что можно делать
- Создавать новые скрипты в папке `_catalog/`
- Добавлять новые категории папок (например, "16 Дипфейки")
- Редактировать HTML/CSS/JS каталога для улучшения UX
- Пишeшь скрипты на Python 3.8+
- Используешь стандартную библиотеку Python (http.server, json, os, subprocess)

## Что нельзя делать
- Не менять структуру папок `00 Новые`, `01-15 Категории`
- Не создавать папки с пробелами или спецсимволами
- Не писать код на других языках без необходимости
- Не использовать npm/node_modules — проект не JS-приложение
- Не делать push без review (всегда пуш в отдельную ветку)
- Не менять `README.md` без согласования (это документация для пользователей)

## Работа с мультимедиа
- Для превью видео используем `ffmpeg` (через imageio-ffmpeg или напрямую)
- Не создавать полноразмерные превью (только 160x100)
- Для аудио — создавать мини-превью через waveform (если есть время)
- Формат аудио: .wav, .mp3, .ogg, .opus — всё поддерживается

## Тегирование и категории
- Теги — для метаданных (качество, автор, источник)
- Категории (01-15) — для быстрого доступа и логической группировки
- Всегда использовать теги для поисковой оптимизации
- Категории и теги в разных файлах (categories.json vs tags.json)

## Команды
```bash
# Просканировать всё
python _catalog/memes.py

# Просканировать только "00 Новые"
python _catalog/memes.py inbox

# Показать дубликаты
python _catalog/memes.py dups

# Обновить каталог и открыть
python _catalog/memes.py serve
```
